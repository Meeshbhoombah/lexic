# lexic/docs
The collected works related to lexic

## User Flows
User navigates to website
- Is signed in
- Is not signed in
    + Does not have Lexe account
        * Does not have lexic account
    + Has Lexe account
        * Has lexic account
        * Does not have lexic account

User installs lexic via their Command-Line Interface

## Features
- Use email for signup
- Decentralized accounts with key storage
    + User can have their key stored, saved, within a Node
        * Can be transfered to another Node
- E2E Encrypted messaging 
- Pay with Lexe
    + Lightnining Network payments (?)
